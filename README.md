# باحث (Baheth) v2.1

محرك بحث في الرسائل والأبحاث الأكاديمية للتربية والعلوم الشرعية.
React 19 + Vite + TypeScript (Strict) + Tailwind (RTL). المصادر: OpenAlex وERIC وCrossref.

## التشغيل محلياً
```
npm install
cp .env.example .env     # ثم ضع بريدك في VITE_CONTACT_EMAIL
npm run dev
```

## البناء
```
npm run build
```

## النشر على Netlify
1. ارفع المشروع إلى GitHub.
2. Netlify ← Add new site ← Import from Git.
3. الإعدادات تُقرأ تلقائياً من `netlify.toml` (Build: `npm run build` ، Publish: `dist`).
4. Site settings ← Environment variables: أضف `VITE_CONTACT_EMAIL`.
5. Deploy. (وكيل ERIC ودعم التوجيه مضبوطان في `netlify.toml`.)

## النشر على Vercel
1. Import من GitHub، والـ Framework سيُكتشف تلقائياً (Vite).
2. أضف `VITE_CONTACT_EMAIL` في Environment Variables.
3. Deploy. (`vercel.json` يحتوي وكيل ERIC ودعم التوجيه.)

## ملاحظات
- ERIC يمر عبر `/api/eric` (Rewrite) لتفادي CORS. أثناء التطوير يتولى ذلك Proxy في `vite.config.ts`.
- فحص العناوين استرشادي ولا يغني عن إفادة الجامعة الرسمية.

## بحث الويب (كتب ومواقع) والمساعد الذكي — Cloudflare Pages

تبويب «بحث الويب» يبحث في المكتبة الشاملة (shamela.ws) ومكتبة نور (noor-book.com) وأرشيف الإنترنت وأي نطاق يضيفه المستخدم، عبر محرك بحث خارجي. والشات العائم وزر «اسأل الذكاء الاصطناعي» يعملان بـ Gemini (الافتراضي) أو OpenAI أو DeepSeek.
كل الاتصالات الخارجية تمر عبر دوال Cloudflare في مجلد `functions/` فلا يوجد أي مفتاح في كود المتصفح.

| المسار | الوظيفة |
|---|---|
| `functions/api/proxy/google.ts` | وسيط بحث الويب (يبني `site:` من نطاقات تم التحقق منها) |
| `functions/api/proxy/ai.ts` | وسيط الذكاء الاصطناعي (مزوّد واحد لكل طلب) |
| `functions/api/proxy/status.ts` | يخبر الواجهة أي الخدمات مفعّلة (دون أي أسرار) |
| `functions/api/eric/[[path]].ts` | وكيل ERIC (بديل Rewrite الخاص بـ Netlify/Vercel) |

### الإعداد
1. Cloudflare Pages ← المشروع ← **Settings ← Variables and Secrets** ← أضف المتغيرات التالية كنوع **Secret** (للإنتاج والمعاينة)، ثم أعد النشر:
   - بحث الويب (مزوّد واحد يكفي): `TAVILY_API_KEY` (الأسهل)، أو `SERPAPI_API_KEY`، أو `GOOGLE_API_KEY` + `GOOGLE_CSE_ID`، أو `SERPER_API_KEY`، أو `BRAVE_API_KEY`. واختيارياً `SEARCH_PROVIDER`.
   - الذكاء الاصطناعي: `GEMINI_API_KEY` (الأساسي)، و`OPENAI_API_KEY` و`DEEPSEEK_API_KEY` اختياريان.
   - اختياري: `GEMINI_MODEL` / `OPENAI_MODEL` / `DEEPSEEK_MODEL` لتغيير النموذج دون تعديل الكود.
2. التجربة المحلية: انسخ `.dev.vars.example` إلى `.dev.vars` ثم `npm run pages:dev` (المنفذ 8788).
3. فحص الأنواع للدوال: `npm run typecheck:functions`.
4. يُنصح بإضافة قاعدة **Rate limiting** في Cloudflare (Security ← WAF) على المسار `/api/proxy/*` لحماية الحصة من الاستنزاف.

### ⚠️ تنبيه عن Google Custom Search
واجهة Custom Search JSON API أُغلقت أمام العملاء الجدد منذ يناير 2026 وتتوقف نهائياً في **1 يناير 2027**. إن كان لديك مفتاح قديم يعمل فهو صالح حتى ذلك التاريخ فقط. لذلك يدعم الوسيط مزوّدين بديلين (Serper وBrave) بنفس الواجهة، والتبديل بمتغير `SEARCH_PROVIDER` فقط دون تعديل الواجهة. راجع شروط وأسعار أي مزوّد قبل الاعتماد عليه.

### ملاحظات
- التلخيص يعتمد على العنوان والمقتطف الذي يرجعه محرك البحث (أو ملخص البحث الأكاديمي)، وليس على النص الكامل للكتاب.
- على Netlify/Vercel لا تعمل هذه الدوال (خاصة بـ Cloudflare)؛ يبقى البحث الأكاديمي يعمل وتظهر رسالة «غير مفعّل» في التبويب الجديد والشات.


## المصادر العالمية والعربية الموسّعة (v2.2)

| المصدر | الطريقة | المفتاح |
|---|---|---|
| PubMed | وسيط `/api/proxy/source?src=pubmed` (NCBI E-utilities) | اختياري `NCBI_API_KEY` |
| DOAJ | وسيط `src=doaj` | لا يحتاج |
| arXiv | وسيط `src=arxiv` | لا يحتاج |
| BASE | وسيط `src=base` | **يتطلب تسجيل IP** (انظر أدناه) |
| دار المنظومة · المنهل · المعرفة | بحث ويب `site:` عبر `/api/proxy/google` | يحتاج مزوّد بحث ويب واحد (Tavily مجاني) |
| الشاملة · نور · بنك المعرفة | بحث ويب `site:` | نفس السابق |
| مستودعات الجامعات المصرية | بحث ويب داخل `edu.eg` | نفس السابق |
| JSTOR · IEEE · Springer | بحث ويب `site:` (روابط ذكية) | نفس السابق |

- **التوحيد:** كل نتيجة تمر عبر `UnifiedResearchResult` ثم `normalizeData` (`src/services/normalize.ts`).
- **الاعتمادية:** `Promise.allSettled` — تعطل أي مصدر لا يوقف الباقي، وتظهر حالته في شارات الحالة.
- **الكاش:** 30 دقيقة في Cloudflare KV (ربط باسم `CACHE`)، وبدونه كاش الحافة تلقائياً.
- **BASE:** لا يقبل طلبات من أي IP؛ سجّل عنوان IP الصادر من Cloudflare لدى BASE عبر نموذجهم المجاني، وإلا ستظهر شارته بحالة خطأ مع الرسالة الموضحة وتعمل بقية المصادر.
- **إضافة مكتبة جديدة:** سطر واحد في `WEB_LIBRARY_GROUPS` داخل `src/services/sources/proxied.ts` (الحد 5 نطاقات لكل مجموعة).
- ⚠️ عند البحث الآن تُرسل ~14 طلباً متوازياً؛ مجموعات الويب الأربع تستهلك 4 طلبات من حصة مزوّد البحث لكل بحث (يخفّفها كاش 30 دقيقة).

## Grok (xAI) كمزوّد ذكاء اصطناعي (v2.4)
- أضف السر `XAI_API_KEY` في Cloudflare (من console.x.ai) فيظهر «Grok (xAI)» تلقائياً في خيارات المساعد، ويمكن مقارنته مع بقية المزوّدين في وضع «الكل».
- النموذج الافتراضي `grok-4.5`، وغيّره بالمتغير `GROK_MODEL` دون تعديل الكود.
- **حماية الرصيد:** الطلبات محدودة بـ 30 في الساعة لكل زائر (`AI_HOURLY_LIMIT` لتغييره)، ويشترط ربط KV باسم `CACHE`. المفتاح يُحاسَب على حسابك، فتابع الاستهلاك من لوحة xAI.

## مفاتيح المستخدمين (BYOK) — التكلفة على المستخدم لا على صاحب المنصة (v2.5)
- صفحة `/settings` («مفاتيحي»): يضيف كل باحث مفتاحه الخاص (Gemini / Grok / OpenAI / DeepSeek) لتفعيل المساعد الذكي، ومفتاح Tavily المجاني اختيارياً للمكتبات العربية.
- المفتاح يُحفظ في `localStorage` بمتصفحه فقط، ويُرسل في ترويسة (`X-User-Key` / `X-Search-Key`) لطلب واحد عبر HTTPS؛ الوسيط لا يخزنه ولا يسجله ولا يدخله في الكاش.
- **الإعداد الموصى به:** لا تضف أي مفتاح ذكاء اصطناعي في Cloudflare. بذلك لا تدفع أنت شيئاً، ويظهر المساعد لمن أضاف مفتاحه فقط. مفاتيح الخادم تبقى اختيارية (مع حد 30 طلباً/ساعة لكل زائر).
- البحث الأكاديمي (OpenAlex، ERIC، PubMed، DOAJ، arXiv ...) مجاني بلا مفاتيح ولا يكلفك شيئاً.

## نتائج بلا سقف عملي + كل المجالات (v2.6)
- **تحميل لا ينتهي عملياً:** التمرير أو زر «تحميل المزيد» يجلب الدفعة التالية من كل مصدر (حتى نحو 1000 نتيجة لكل مصدر)، وتتراكم النتائج وتُدمج دون تكرار. «لا نهائي» الحقيقي مستحيل لأن لكل مصدر عمقاً أقصى تحدده واجهته؛ لذلك نضيف مصادر أكثر.
- **مصادر إضافية مجانية:** Europe PMC وZenodo وHAL (إضافة إلى PubMed وDOAJ وarXiv وBASE وOpenAlex وCrossref وCORE وOpenAIRE وSemantic Scholar وERIC).
- **كل المجالات افتراضياً:** مجال «كل المجالات» بلا قيد موضوعي، والقيد على الجهات المصرية صار اختيارياً (كان افتراضياً).
- **ترجمة تلقائية للاستعلام:** القاموس المحلي أولاً، ثم MyMemory المجاني عبر `/api/proxy/translate` (كاش 24 ساعة)، فتصل الكلمات العربية إلى القواعد الإنجليزية. اختيارياً: `MYMEMORY_EMAIL` يرفع الحصة اليومية.
- **بحث الويب للمكتبات العربية** يبقى للصفحة الأولى فقط لحماية حصة المزوّد المجانية.

## الحسابات بـ Google + المفضلة + حصة يومية لكل حساب (v3.0)
**ما الذي تغيّر عند التفعيل:**
- زر «تسجيل الدخول بحساب Google» في الشريط العلوي، وصفحة `/favorites` لحفظ الأبحاث، وعدّاد الحصة في `/settings`.
- بحث المكتبات العربية (يستهلك Tavily الخاص بك) والمساعد الذكي بمفاتيح المنصة **يتطلبان الدخول** ويُحسبان بحصة يومية لكل حساب (`WEB_DAILY_LIMIT` = 40، `AI_DAILY_LIMIT` = 20). من يضع مفتاحه الخاص لا يُحسب عليه شيء ولا يحتاج دخولاً.
- البحث الأكاديمي (OpenAlex، PubMed، ...) يبقى مفتوحاً للجميع بلا دخول.
- **اختياري بالكامل:** بدون المتغيرات الثلاثة أدناه تعمل المنصة كما كانت.

**خطوات التفعيل:**
1. **Google Cloud Console** ← APIs & Services ← Credentials ← Create credentials ← OAuth client ID ← نوع Web application. في Authorized JavaScript origins أضف نطاق موقعك (مثل `https://baheth.pages.dev` ونطاقك الخاص). لا تحتاج Redirect URI. اضبط OAuth consent screen (اسم التطبيق وبريدك). انسخ **Client ID**.
2. **D1:** `npx wrangler d1 create baheth-db` ثم `npx wrangler d1 execute baheth-db --remote --file=migrations/0001_init.sql`.
3. **Cloudflare Pages ← Settings ← Bindings:** أضف D1 database باسم `DB` يشير إلى `baheth-db`.
4. **Variables and Secrets:** `GOOGLE_CLIENT_ID` (متغير عادي) و `SESSION_SECRET` (Secret، ولّده بـ `openssl rand -base64 48`).
5. أعد النشر. افتح `/api/proxy/status` وتأكد أن `auth` يحوي `clientId`.

**الأمان:** رمز Google يُتحقق منه بالتوقيع RS256 والجمهور (aud) والمُصدر والانتهاء والبريد الموثّق؛ الجلسة كوكي `HttpOnly; Secure; SameSite=Lax` موقّع HMAC لمدة 30 يوماً؛ الطلبات المعدِّلة تتحقق من `Origin` (حماية CSRF)؛ المفضلة تُنقّى وتُحدّ بـ 500 عنصر لكل حساب.

**تنبيه عن حدود Cloudflare المجانية:** Workers KV المجاني يسمح بنحو 1000 عملية كتابة يومياً، وكاش المصادر يكتب عند كل بحث جديد، فقد يمتلئ مع كثرة المستخدمين (القراءة لا تتأثر والبحث يستمر بلا كاش). إن حدث ذلك: اربط نطاقاً خاصاً ليعمل كاش الحافة، أو انتقل إلى خطة Workers المدفوعة الصغيرة. جداول D1 (الحسابات والمفضلة والحصة) لها حدود مجانية أوسع بكثير.

## النسخة 3.1 — مراجعة هندسية شاملة (أمان، دقة علمية، ميزات بحثية، واختبارات)

### إصلاحات أمنية
- **مفتاح CORE لم يعد في المتصفح:** كان `VITE_CORE_API_KEY` يُدمج في كود الواجهة. نُقل إلى الخادم كسرّ `CORE_API_KEY` (مصدر `core` في الوسيط). أضِفه في Cloudflare كـ Secret.
- **حماية الحصة من الاستنزاف — ثلاث طبقات:** (1) حد لكل IP على كل واجهة (بحث الويب 30/ساعة، المصادر 600/ساعة، الترجمة 40/ساعة، المساعد 60/ساعة)، (2) **سقف يومي عام** لكل خدمة محدودة الحصة (`WEB_GLOBAL_DAILY_CAP` الافتراضي 100، فاضبطه على حصة Tavily الشهرية ÷ 30)، (3) حصة يومية لكل حساب. العدّادات في D1 (الأدق)، وإلا KV، وإلا ذاكرة النسخة (أضعف). **أضف أيضاً** قاعدة Rate Limiting من لوحة Cloudflare (Security ← WAF) على المسار `/api/*` كطبقة أمام الدوال، وفعّل Bot Fight Mode.
- **ترويسات أمان وCSP** (`public/_headers`): منع التضمين، `nosniff`، سياسة محتوى تسمح فقط بالمصادر المستخدمة. إن ظهر في وحدة تحكم المتصفح حظر لمورد مشروع بعد النشر فاضبط `connect-src`.
- **مفاتيح المستخدمين:** تُحفظ افتراضياً في `sessionStorage` (تُمحى بإغلاق التبويب)، والتذكّر على الجهاز اختياري.
- **حذف الحساب:** `DELETE /api/auth/account` + زر في صفحة «مفاتيحي».
- **الهجرات:** نفّذ أيضاً `migrations/0002_limits_library.sql` (جدول الحدود وعمود الملاحظات):
  `npx wrangler d1 execute baheth-db --remote --file=migrations/0002_limits_library.sql`

### إصلاحات الدقة العلمية
- **فلتر السنوات:** يستبعد مجهولة السنة، وتُعرض ملاحظة بعدد المخفي.
- **فلتر القسم:** تُطبَّق مطابقة المصطلحات (عربي/إنجليزي) على العنوان والملخص بعد الجلب، فلا تظهر نتائج خارج القسم.
- **فلتر مصر:** صار يعتمد على **التحقق من الجهة** (رمز الدولة من OpenAlex/OpenAIRE، أو جامعة مصرية معروفة، أو نطاق `.eg`)، وأُزيل إلصاق كلمة Egypt/مصر بالاستعلام.
- **الترتيب:** ترتيب موحّد للصلة (BM25 مبسّط بوزن العنوان×3 + تغطية مصطلحات + عبارة كاملة + استشهادات/حداثة كعوامل ثانوية) بدل التناوب بين المصادر، ولا يتقدم أي نتيجة بلا تطابق نصي على نتيجة متطابقة.
- **فاحص التقارب:** صار «استرشادياً» بإعلان صريح لنطاقه وحدوده (ألفاظ العنوان فقط، قواعد مفتوحة فقط، ليس كاشف سرقة)، ولم يعد يستهلك حصة بحث الويب.

### ميزات جديدة
- **/theses** بحث موجّه للرسائل الجامعية المصرية والعربية مع فهارس رسمية للتحقق اليدوي.
- **/library** مكتبة مراجع (محلية بلا حساب، أو سحابية بالحساب) مع ملاحظات، بحث، رفع المكتبة المحلية للحساب، استخراج بيانات من DOI (Crossref).
- **توثيق APA 7 / Chicago 17 / MLA 9** بالعربية والإنجليزية مع تحذيرات الحقول الناقصة بدل اختلاقها.
- **تصدير** قائمة المراجع إلى Word (.docx حقيقي بدعم RTL وتنسيق معلّق) وPDF (عبر طباعة المتصفح لسلامة العربية) وBibTeX وRIS.
- **/assistant مساعد البحث العلمي:** خطة بحث، إطار نظري، دراسات سابقة، أسئلة وفروض، فجوة بحثية — **من مراجع مكتبتك فقط**؛ الخادم يرقّمها ويفرض قواعد عدم الاختلاق، و«حارس الاستشهادات» يفحص الناتج (إحالات خارج القائمة، (مؤلف، سنة) مختلقة، DOI/روابط غريبة، أرقام صفحات)، وقائمة المراجع تُولَّد من بياناتك لا من النموذج.
